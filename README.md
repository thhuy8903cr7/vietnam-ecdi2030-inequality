# Socioeconomic Inequalities in Early Childhood Development in Vietnam

This repository contains the R scripts associated with the manuscript entitled **"Socioeconomic inequalities in early childhood development in Vietnam: A national decomposition analysis."**

## Data source

The study used data from the 2020–2021 Vietnam Multiple Indicator Cluster Survey (MICS6).

## R scripts

- `merge_data.R`: Data preparation and merging.
- `analysis_final.R`: Statistical analyses conducted for the study.

## Data availability

The underlying MICS6 data are not redistributed in this repository. Access to the data is subject to the data provider's conditions.

## Reproducibility

The R scripts are provided to support research transparency and reproducibility. The underlying MICS6 dataset is required to reproduce the analyses.
